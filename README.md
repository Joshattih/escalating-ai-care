# Escalating AI Care: A Right to Holdout

Year-2 PhD project, University of New Mexico (Joshua Attih; advisor Melanie Moses).

**Question.** When a group of clinicians must set the rule for when an AI screening tool stops talking to a MBH patient and hands over to a person, how is that rule reached, who cannot live with it, and what does their position cost?

**This repository holds**

- `data/rules.csv`, `data/rules.json`: 773 rules extracted from 14 official severity and escalation rating systems (2007 to 2026), one rule per row, each traceable to a page of its source document. This is the baseline the study's statements are drawn from.
- `docs/`: the project site (GitHub Pages). First page: an explorer for the rules table.

The site: https://joshattih.github.io/escalating-ai-care/
